## M12.1 — blocks + font

- `apps/ui/src/terminal/blocks.ts` — OSC 133 phases after xterm write commits;
  failed `commandEnd` → danger left rule + overview ruler.
- Output pump emits data segments **before** each OSC 133 block event so markers
  land on the correct lines (not collapsed onto one flush).
- Hover: copy command, copy output, rerun (insert, no Enter).
- JetBrains Mono Variable as the terminal / `--font-mono` default.

## M12.2 — scroll-jump

Agent CLIs (Claude Code, Codex, …) redraw with **DEC 2026** sync blocks that
contain **ED2/ED3**. xterm.js resets `viewportY` on those erases even inside a
sync block ([xtermjs/xterm.js#5801](https://github.com/xtermjs/xterm.js/issues/5801)).

Mitigations in [`registry.ts`](../apps/ui/src/terminal/registry.ts) /
[`syncFilter.ts`](../apps/ui/src/terminal/syncFilter.ts):

1. `scrollOnEraseInDisplay: true` — iTerm-like ED2 (push viewport into
   scrollback instead of wiping it).
2. **Strip `CSI 2 J` / `CSI 3 J` only while DEC 2026 sync is active** — same
   approach as Pane’s filter; `clear` / vim / htop unchanged.

## M12.4 — reattach scrollback

[`@xterm/addon-serialize`](https://github.com/xtermjs/xterm.js) snapshots the
buffer on project tab detach (close / lock / window reclaim) into **IndexedDB**
keyed by `projectId` ([`scrollback.ts`](../apps/ui/src/terminal/scrollback.ts)).
`openProject` restores the snapshot into the new terminal before the launch
script / mux attach, buffering live PTY events until restore finishes so early
output is not dropped. Multi-window adopt restores the same way. Dispose /
lock / reclaim **await** persist before tearing down xterm.

- Cap: 2500 lines / ~400KB
- `excludeAltBuffer: true` — don’t restore a stale vim/TUI screen
- Project delete clears the IndexedDB snapshot
- **Same-device** for now; cross-device blob sync via vault is a follow-up
- `SyncClearFilter.reset()` on dispose so a stuck DEC 2026 state cannot leak

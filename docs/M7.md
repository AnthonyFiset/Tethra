# M7 — Real terminal

Agent-grade TTY conformance, OSC 133 command blocks, and splits / multi-window
over the session registry. Detail and rationale live in
[`ROADMAP-v2.md`](../ROADMAP-v2.md). Terminal feel / scroll-jump → M12 in
[`ROADMAP-v3.md`](../ROADMAP-v3.md).

## What shipped

### Terminal conformance
- xterm: `@xterm/addon-clipboard` (OSC 52), `@xterm/addon-unicode11`, mouse
  modes honored when apps request them, bracketed paste on, `macOptionIsMeta`.
- Local PTY: `TERM=xterm-256color` + `COLORTERM=truecolor`.
- OSC 7 handler tracks per-session working directory.

### OSC 133 (core)
- Streaming parser in `crates/core/src/terminal/`.
- Output pump tees block events beside raw bytes on the app event bus
  (`terminal-event`), so any OS window can attach to a session.

### Shell integration
- Wrapper delivery (local temp rcfile / SSH bash `--rcfile` exec).
- `Host.shell_integration` preference (`Auto` / `Disabled`) in vault + host form.

### Splits / windows
- Layout tree (`split(h|v)`, drag sash resize, zoom pane) in the frontend.
- Single-column under 768px (focused leaf only).
- Shortcuts: `⌘\` split right, `⌘⇧\` split down, `⌘⇧↵` zoom, `Esc` exit zoom.
- OS windows are a presentation layer: New window / Move tab to new window;
  closing a secondary window reclaims tabs to main without killing Rust sessions.

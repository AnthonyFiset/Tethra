# M6.2 — Sync you don't think about

Background sync, opt-in password sync, coordinated re-key, iOS CI guard, and
auto-mirror updates on the sync host. Detail and rationale live in
[docs/archive/ROADMAP-v2.md](../archive/ROADMAP-v2.md).

## What shipped

### Opt-in `sync_secret`
- `PasswordIdentityRecord.sync_secret` (default `false`) drives `local_only`.
- Host editor checkbox: **Sync password to other devices**.
- SSH private keys remain device-local (`PROJECT.md` §7).

### Background sync
- Debounced sync after unlock, host CRUD, SSH import, and password change.
- 5-minute interval while unlocked.
- Window focus / visibility refresh from the UI.
- **Sync now** remains in Vault sync settings for certainty.

### Coordinated re-key
- Changing the master password publishes a `rekey_from` attestation on the
  shared header (vault-key sealed proof of the previous wrap).
- Peers adopt the new wrap on next sync, then unlock with the new password —
  no reset-and-rejoin.

### iOS portability guard
- CI job `ios-core-check` on `macos-latest`:
  `cargo check -p core --target aarch64-apple-ios`.

### Auto-mirror timer
- `tethra-sync-server install-updates-timer` (also offered in the setup wizard).
- Hourly `fetch-updates` via systemd user timer. See [`UPDATES.md`](UPDATES.md).

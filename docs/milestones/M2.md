# M2 desktop shell

M2 adds the Tauri v2 desktop shell, React UI, persistent xterm sessions, tabs,
and responsive host navigation.

> Hosts and credentials moved to the encrypted vault in
> [M3](M3.md). Do not configure SSH hosts through environment variables.

## Run locally

```bash
cd apps/tauri/src-tauri
npx --prefix ../../ui tauri dev
```

Create or unlock the vault in the UI, then add hosts through the sidebar.

## Build

```bash
cd apps/tauri/src-tauri
npx --prefix ../../ui tauri build --debug --no-bundle
```

## IPC boundary

[`apps/ui/src/lib/ipc.ts`](../apps/ui/src/lib/ipc.ts) is the only frontend
module that imports Tauri APIs. Rust response/event types are generated with
`ts-rs` into `apps/ui/src/lib/generated/`.

Terminal output uses a Tauri channel. Rust batches output every 10 ms, caps each
message at 64 KiB, and drops the middle of an overgrown pending buffer with a
visible marker. Resize messages are debounced to 100 ms in the xterm registry.

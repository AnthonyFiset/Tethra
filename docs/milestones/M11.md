# M11 — Provider + agent catalogs

Canonical plan: [ROADMAP.md](../../ROADMAP.md). Catalogs are **data**, not
compiled special cases. Bundled snapshot → (later) sync-server fetch → vault
overrides win.

## Goals

1. **Provider catalog** — one `ProviderPreset` shape; OpenAI-compat covers most
   hosts (OpenRouter, Ollama, LM Studio, …).
2. **Paste-key UX** — pick provider → paste key → **Test** (`GET /models`) →
   live model picker → save to vault (`sync_secret` opt-in).
3. **Agent catalog** — detect / install coding agents; project flow with
   installed vs available.

## Build order

| Slice | Scope | Status |
|---|---|---|
| **M11.1** | Bundled provider JSON + `test_provider` + Assist settings UX | **Done** |

## M11.1 — providers

### Core (`crates/core`)

- `data/assist_providers.json` — Anthropic, OpenAI, OpenRouter, Google, xAI,
  DeepSeek, Groq, Together, Fireworks, Mistral, Cerebras, Ollama, LM Studio,
  vLLM, Custom.
- `assist::catalog` — `ProviderPreset`, `bundled_presets`, `headers_for_base_url`.
- `assist::test_provider` — Rust-side `GET …/models`.

### IPC / UI

- `list_assist_presets`, `assist_test_provider`
- Assist settings: preset → key → Test → live models → Save

## M11.2 / M11.3 — agents

### Core

- `data/agents.json` — Claude Code, Codex, Aider, Antigravity (`agy`), OpenCode,
  Shell; Gemini marked **Deprecated → antigravity**. Antigravity install uses the
  official `antigravity.google/cli` scripts (not npm).
- `agents::catalog` — `AgentPreset`, install hints per OS, `resolve_agent_for_launch`
  (follows successors).
- `builtin_agents()` loads from JSON (no hardcoded vec).

### IPC / mux

- Rich `AgentSpecDto` (status, successor, install hints, byok_env stored for later).
- `probe_host_tools` install/reason for agent CLIs come from the catalog
  (tmux/zellij remain hardcoded).

### UI

- Project form: catalog picker with Installed / Available (probe), copy-install
  for missing agents, deprecated rows redirect to successor. Before probe
  completes (or with no remote host), status is neutral — not “Installed”.
- `openProject` follows deprecated successors, **persists** the successor on the
  project, and shows a one-line migration notice.
- Launcher / Sidebar / Palette show agent display names (via successor resolve).

### Deferred

- **BYOK** — inject vault Assist keys into agent `byok_env` at launch
- Sync-server / public URL catalog fetch
- Full roadmap seed (Cursor CLI, Goose, Cline, …) as data-only PRs
- Vault-stored custom AgentSpec / Custom command preset

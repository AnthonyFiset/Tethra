# M5 SFTP UI

M5 adds a dual-pane SFTP browser with local and remote file management, drag-and-drop transfers, and a session-scoped transfer queue that supports pause and resume.

## Behavior

- Open **Files** from the host sidebar to start a persistent SFTP browser tab.
- The left pane lists the local filesystem starting at the desktop home directory.
- The right pane lists the remote host starting at the canonicalized `.` directory.
- Both panes support navigation, refresh, create folder, rename, and delete.
- Drag a file from one pane onto the other to enqueue an upload or download.
- The transfer queue runs one file at a time per SFTP tab.
- **Pause** cancels the active transfer while keeping the partial file on disk.
- **Resume** restarts from the retained byte offset during the current app session.
- Locking the vault, idle auto-lock, or suspend closes SFTP sessions and cancels active transfers.

`ProxyJump` remains stored metadata only; live jump-host routing is **M13**
(see `ROADMAP.md`; promote only if jump is blocking today).

## Secret boundary

- Hosts are referenced by ID only from JavaScript.
- Local and remote paths are plain strings; credentials never cross IPC.
- Transfer commands open a dedicated SFTP connection per active transfer so browsing stays responsive.
- Passwords and key material are never stored in React state or browser storage.

## Use

1. Unlock the vault.
2. Select **Files** beside a host.
3. Browse local and remote directories.
4. Drag files between panes or use **Upload selected** / **Download selected**.
5. Monitor progress in the queue dock; pause, resume, retry, or cancel as needed.

## Limitations

- Folder transfers are not supported in M5.
- The transfer queue is not persisted across app restarts.
- Resume only applies to partial files retained during the current session.

# M4 SSH config import

M4 imports concrete host aliases from the desktop user's `~/.ssh/config` into
the encrypted vault.

## Behavior

- Parsing is portable core logic built on `russh-config`.
- Only concrete `Host` aliases are offered for import. Wildcard and negated
  patterns remain defaults and are not turned into saved hosts.
- Hostname, user, port, and `ProxyJump` are resolved with matching `Host *`
  defaults.
- Selecting a host automatically includes a referenced jump-host alias.
- The import is one SQLite transaction. Re-importing an alias updates its
  endpoint metadata while preserving its password identity and trusted host key.
- `ProxyJump` is persisted as `Host.jump_host_id`. Using jump hosts for live
  connections remains an **M13** feature (`ROADMAP.md`).

`Match` blocks are skipped because `russh-config` does not evaluate their
conditions safely. `Include`, `ProxyCommand`, and multi-hop jump chains produce
visible compatibility warnings instead of being silently treated as fully
supported.

## Secret boundary

The config path and contents stay in Rust. IPC exposes only resolved host
metadata and warnings. `IdentityFile` is detected for the preview, but private
key paths or key material are not returned to JavaScript and private-key
identity import remains deferred.

## Use

1. Unlock the vault.
2. Select **Import** in the Hosts sidebar.
3. Review the aliases discovered in `~/.ssh/config`.
4. Select aliases and confirm the import.
5. For hosts that need credentials, edit the imported host and add a password.

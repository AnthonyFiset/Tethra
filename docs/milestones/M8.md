# M8 — Projects and agents

First-class projects that sync through the vault, one-click open → cd → launch
agent, and persistent remote sessions via `tmux`. Detail and rationale live in
[docs/archive/ROADMAP-v2.md](../archive/ROADMAP-v2.md). Forward plan: [ROADMAP.md](../../ROADMAP.md)
(agent presets become synced catalogs in M11).

## Goals

1. **`Project`** — Local `{ path }` or Remote `{ host_id, path }`; syncs like Host.
2. **`AgentSpec`** — built-in presets (data only) + optional custom later.
3. **Open project** — connect/reuse → `cd` → launch default (or chosen) agent.
4. **Persistence** — defaults to in-app detach (tab close → reopen). When tmux
   is detected, projects use `tmux new-session -A` so sessions survive quitting
   Tethra. Opening Local / a project shows an OS-specific install hint if tmux
   is missing (copyable command; optional “Install for me” via Homebrew /
   passwordless sudo). Remote projects always attempt the mux script on the host.
5. **Running sessions** — list/reattach for **remote** persistent agents
   (cross-device via vault sync). Local resume is same-machine via reopen.

## Running sessions

Opening a remote project with a persistent agent upserts a vault
`RunningSession` (one per project). It syncs like hosts/projects, so another
device can show it under **Running** and reattach with the same
`tmux new-session -A` path. **Closing a tab only detaches** (tmux keeps
running). **× on Running kills** the mux session on the host and clears the
vault marker.

# Development notes

## M1 quick start

```bash
# Unit tests
cargo test -p core

# CLI against a real host
cargo run -p core --example ssh-client --features cli -- \
  exec --host example.com --user alice --identity ~/.ssh/id_ed25519 -- \
  uname -a

# Integration tests (Docker)
docker compose -f crates/core/tests/docker-compose.yml up -d
cargo test -p core --test ssh_integration -- --ignored --test-threads=1 --nocapture
docker compose -f crates/core/tests/docker-compose.yml down -v
```

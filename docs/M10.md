# M10 — Launcher and workspace

Canonical intent: [`ROADMAP-v3.md`](../ROADMAP-v3.md) §M10.  
Status: **Done** (polish pass complete; ephemeral quick-connect without vault deferred).

## Goals

1. **Two modes** — Launcher (dashboard) ↔ Workspace (current terminal UI).
2. **Resume first** — running tmux sessions across hosts at the top of Launcher.
3. **Sidebar only in Workspace** — Open tabs, Running, Hosts, Projects.
4. Mode rules that feel designed (last-tab → Launcher; never kill on view change).

## Mode rules (acceptance)

- Closing the **last** tab returns to Launcher; closing a non-last tab does not.
- Launcher never kills sessions — Running stays visible in Resume.
- `Cmd/Ctrl+K` works in both modes and can cross the boundary.
- `Cmd/Ctrl+Escape` toggles Launcher ↔ Workspace when tabs exist.
- Under 768px, Launcher is the default; sidebar is a drawer in Workspace.

## Deferred (intentionally)

- **Ephemeral quick connect** that never touches the vault (needs ad-hoc SSH IPC).
- **`@tanstack/react-table`** wiring — dep installed; lists use sort/filter without it until grouping UX needs it.
- **Host tag editing** in the form — tags display when present on the host record.

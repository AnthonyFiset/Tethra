# M9 — Assist

Deliberately small: `Cmd/Ctrl+I` asks a vault-backed model for a shell command
that lands **in the input, not the shell**. Detail in
[`ROADMAP-v2.md`](../ROADMAP-v2.md).

## Goals

1. **Propose** — NL prompt + session context → single shell command.
2. **Insert without Enter** — PTY bytes only; user edits and presses Enter.
3. **ApprovalGate** — `Action::AssistInsert` before returning a command.
4. **Pluggable providers** — Anthropic, OpenAI, OpenAI-compatible base URL.
5. **API keys** — vault items with `sync_secret` (default off).
6. **Explain** — same call with transcript context; prose in the Assist panel.
